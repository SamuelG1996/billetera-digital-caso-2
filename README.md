Billetera Digital

Este proyecto consiste en el desarrollo de una billetera digital utilizando Angular CLI versión 22.2.7.

Descripción del proyecto

La aplicación permite gestionar un saldo disponible mediante el registro de gastos y recargas, además de visualizar el historial de movimientos realizados.

Componentes

Se desarrollaron dos componentes funcionales:

- BilleteraComponent: administra el saldo disponible y el historial de movimientos.
- NuevoMovimientoComponent: permite registrar gastos y recargas, validando el monto ingresado y el saldo disponible.

Instalación y ejecución

Para descargar y ejecutar el proyecto, seguir los siguientes pasos:

1. Descargar el proyecto

- Ingresar al repositorio de GitHub.
- Hacer clic en el botón Code.
- Seleccionar la opción Download ZIP.

2. Descomprimir el proyecto

- Ubicar el archivo ZIP descargado.
- Extraer su contenido.
- Se obtendrá una carpeta llamada billetera-digital-caso-2-main.

3. Ubicar la carpeta del proyecto

- Opcionalmente, copiar la carpeta extraída al Escritorio o a otra ubicación de preferencia.
- Verificar que la carpeta seleccionada contenga directamente los archivos package.json y angular.json, además de las carpetas src y public.

4. Abrir el proyecto en Visual Studio Code

- Abrir Visual Studio Code.
- Seleccionar File → Open Folder.
- Elegir la carpeta que contiene directamente los archivos del proyecto.

5. Instalar las dependencias

- Abrir una terminal en Visual Studio Code mediante Terminal → New Terminal.
- Ejecutar el siguiente comando: **npm install**
- Esperar a que finalice la instalación de las dependencias.

6. Iniciar la aplicación

- Una vez instaladas las dependencias, ejecutar: **ng serve -o**

La aplicación se abrirá automáticamente en el navegador y estará disponible en: http://localhost:4200/
